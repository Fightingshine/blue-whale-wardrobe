# 大肥鱼皮肤库

管理蓝色大肥鱼的设定图皮肤，并从共创图鉴自动同步已审核投稿。

在 AstrBot 的插件卡片打开「皮肤库」，可以预览原图、启用/停用、设置关键词、编辑外观补充说明和调整日报轮换权重。使用 AstrBot 原有的登录鉴权，不需要另开端口或填写 GitHub Token。

## 自动上线流程

1. 同学在衣橱网站投稿设定图。
2. 维护者审核 GitHub Issue，为它添加 `已收录` 标签。
3. 网站 GitHub Actions 构建成功，投稿进入 `skins/catalog.json`。
4. 本插件默认每 5 分钟检查网站，串行下载并校验图片，原子发布新目录。
5. 生图插件实时读取目录，之后按新关键词画图。允许参与日报的投稿自动加入轮换。

实际延迟是网站构建用时加上最多一个同步间隔；网站构建失败时不会上线。没有新内容时使用 ETag 减少流量。同步只读取目录和图片，不调用聊天或生图模型，不消耗模型 Token，不自动发送群消息。

网站取消 `已收录`、关闭或删除投稿后，网站重新发布的目录将移除该皮肤。下一次成功同步会停用它，保留原图和历史信息。网站短暂断网、哈希不匹配或目录无效时，沿用上一次完整目录。

## 兼容与安装

- AstrBot >=4.29.1。
- 依赖 `aiohttp`、`Pillow`；已有 AstrBot 环境通常已经具备。
- 需要配套的 `astrbot_plugin_kuaiai_image >=0.7.0` 动态皮肤适配器；仅安装管理插件不会让旧版生图插件识别新皮肤。
- 原装、冬装、毛衣、像素风四张历史原图需要已存在于生图插件的 `assets` 目录，并与 `builtins.json` 的校验值一致。其他机器部署时应根据自己的已确认原图维护基础定义，不能跳过校验。
- 当前机器已经部署配套适配器。`integrations/kuaiai_image` 保留适配源码，供后续维护和迁移；管理插件与生图插件不互相导入，不依赖启动顺序。

下载依赖默认使用国内镜像：

```powershell
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 使用

群里输入 `/皮肤库` 查看已启用皮肤及关键词。画图时使用例如：

```text
@蓝色大肥鱼 帮我画一张短发大肥鱼庆祝选课成功的图
```

管理员可使用：

```text
/同步皮肤
/停用皮肤 短发
/启用皮肤 短发
```

配置 `site_url` 为可信图鉴的 HTTPS 根地址，默认 `https://blue-chubby-whale.cyou/`。`sync_interval_seconds` 默认为 300，最小 60。`enabled` 仅控制自动同步，手动同步和现有已启用皮肤仍可使用。

## 皮肤规则

- 未指定皮肤时默认原装；原装默认人设保持启用。
- 已停用或已撤销收录的皮肤，明确点名时提示不可用，不偷偷改为原装。
- 本地停用、关键词、外观说明和权重设置不会被后续同步覆盖。「恢复来源设置」可以清除这些本地设置。
- 来源未允许参与日报时，本地也不能强行加入轮换。
- 日报基础权重：原装 1，其他默认 3。最近一次成功生成的皮肤权重为 0，最近第二/第三次分别乘 0.5/0.8；之后恢复。权重不等于固定概率。
- 只统计真实生成成功的历史。停用或撤销收录的旧皮肤保留定义，避免破坏历史账本。
- 共创皮肤必须上传自己的设定图进行图生图，不能降级为纯文字生图。外观说明只作补充，实际参考图优先；较长说明仅取前 160 字进入模型提示，避免挤占日报分镜内容。
- 参考图按 SHA-256 内容寻址，保留原始字节；网站更新图片会得到新的缓存文件，不覆盖历史图片。

## 数据与接口

管理状态位于 `StarTools.get_data_dir('astrbot_plugin_whale_skins')/state.json`。

生图插件资产目录中新增：

```text
assets/
  whale_skin_library.json       原子发布的动态皮肤目录
  skin_library/<sha256>.<ext>   共创设定图原图
```

不修改生图 API Key、额度、群授权、定时任务或历史生成记录。参考图只允许同源 HTTPS 下载；拒绝内部网络地址、外部重定向、路径穿越、超大图片和多帧图片，核验文件格式、尺寸和 SHA-256。

Web API 前缀是 `/api/plug/astrbot_plugin_whale_skins/page`，需要 AstrBot 登录。支持 `GET /status`、`POST /sync`、`POST /skins/<id>`、`POST /skins/<id>/reset`、`GET /skins/<id>/preview` 和 `GET /skins/<id>/reference`。保存设置需携带当前目录 `revision`，防止覆盖其他管理员或同步任务的新修改。

旧缓存不自动删除；当皮肤长期更新导致缓存增多时，可停用相关皮肤、备份并确认没有进行中的生图任务后由维护者清理。插件不提供会误删原始素材的自动清理按钮。

```powershell
python -m unittest discover -s tests -v
```

测试覆盖同步、撤销收录、网络失败、图片校验、本地覆盖、管理员鉴权、并发与动态轮换。适配器还需在实际 AstrBot 环境验收，测试通过不代表完成线上安装。
